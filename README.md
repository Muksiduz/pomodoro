# GROVE — Pomodoro Productivity Garden

## Run it
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, Firefox, or Safari.
3. No npm install, build step, account, or backend is required.

## Features
- Pomodoro focus, short break, and long break timers
- Custom focus/break durations and tree type
- A tree planted after every completed focus session
- Custom work tags (e.g. Study, Coding, Motion Design); every session stores its selected tag
- Weekly/monthly tree charts and focus-by-tag breakdown
- Forest gallery, daily tasks, streaks, and focus history
- Ambient rain/birds sound effects and visual themes
- LocalStorage persistence

## Data
All records are stored in browser LocalStorage under `grove_pomodoro_v2`.
Data is local to this browser/device. Clearing site data or using another browser may make it unavailable.
